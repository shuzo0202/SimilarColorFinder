# 色差計算検証アプリ README

このリポジトリの `app.py` は、Streamlit で色差検索を行うアプリケーションです。ユーザーが入力した Lab 値に対して、CSV 内の Lab データと CIEDE2000 で色差を計算し、しきい値以内の色を抽出します。

## 前提条件

- Python 3.10 以降
- `requirements.txt` に記載のライブラリ

## セットアップ

```bash
pip install -r requirements.txt
```

## 実行方法

```bash
streamlit run app.py
```

## 使い方

1. サイドバーから CSV ファイルをアップロードします。
2. 「銘柄名・色名で検索」で候補を絞るか、カラーピッカー／Lab スライダーで入力色を決めます。
3. `KL` と色差しきい値を調整します。
4. 色差がしきい値以下の色が一覧表示されます。

## CSV 形式

以下の列を含む CSV が必要です。

- `収録MS`
- `商品コード`
- `銘柄名`
- `色名`
- `L`
- `a`
- `b`

## 色差計算（CIEDE2000）アルゴリズム詳細

このアプリでは `app.py` 内の独自実装 `ciede2000()` を用いて CIEDE2000 色差を計算しています。実装の主要ステップは以下の通りです。

### 1. 入力

- 入力は 2 つの Lab 値 `lab1 = (L1, a1, b1)` と `lab2 = (L2, a2, b2)`
- 補正係数として `k_L, k_C, k_H`（明度・彩度・色相の重み）を受け取ります

### 2. 明度差と平均明度

- 明度差:  
  `ΔL = L2 - L1`
- 平均明度:  
  `L̄ = (L1 + L2) / 2`

### 3. 彩度と平均彩度

- 彩度:
  `C1 = sqrt(a1^2 + b1^2)`  
  `C2 = sqrt(a2^2 + b2^2)`
- 平均彩度:  
  `C̄ = (C1 + C2) / 2`

### 4. a* 補正係数 G と補正 a*

色相周りの非線形性を補正するための係数を導入します。

- 補正係数:
  `G = 0.5 * (1 - sqrt(C̄^7 / (C̄^7 + 25^7)))`
- 補正 a*:  
  `a1' = a1 * (1 + G)`  
  `a2' = a2 * (1 + G)`

### 5. 補正彩度と彩度差

- 補正彩度:
  `C1' = sqrt(a1'^2 + b1^2)`  
  `C2' = sqrt(a2'^2 + b2^2)`
- 彩度差:
  `ΔC' = C2' - C1'`

### 6. 補正色相角と色相差

色相角を `-180°〜180°` で扱わず、`0°〜360°` に正規化します。

- 補正色相角:  
  `h1' = atan2(b1, a1')`  
  `h2' = atan2(b2, a2')`  
  ただし `0°〜360°` に正規化。

色相差は 360° の循環を考慮して決定します。

- `Δh'` は以下の条件分岐で算出:
  - `|h2' - h1'| <= 180°` → そのまま差分
  - `h2' - h1' > 180°` → `Δh' = h2' - h1' - 360°`
  - `h2' - h1' < -180°` → `Δh' = h2' - h1' + 360°`

色相差は以下で定義:

`ΔH' = 2 * sqrt(C1' * C2') * sin(Δh' / 2)`

### 7. 平均色相角

色相角の平均値も 360° の循環を考慮して求めます。

`h̄' = (h1' + h2') / 2`  
ただし `|h1' - h2'| > 180°` の場合は 360° を加算して平均。

### 8. 色相重み係数 T

色相の非線形性補正項:

```
T = 1
  - 0.17 * cos(h̄' - 30)
  + 0.24 * cos(2h̄')
  + 0.32 * cos(3h̄' + 6)
  - 0.20 * cos(4h̄' - 63)
```

### 9. 回転項と補正係数

- 色相角の特異領域補正:
  `Δθ = 30 * exp(-((h̄' - 275)/25)^2)`
- 彩度に関する補正係数:
  `R_C = 2 * sqrt(C̄^7 / (C̄^7 + 25^7))`
- 回転項:
  `R_T = -sin(2 * Δθ) * R_C`

### 10. 重み係数 S_L, S_C, S_H

人間の視覚特性に合わせて明度・彩度・色相方向の寄与を調整します。

- `S_L = 1 + (0.015 * (L̄ - 50)^2) / sqrt(20 + (L̄ - 50)^2)`
- `S_C = 1 + 0.045 * C̄`
- `S_H = 1 + 0.015 * C̄ * T`

### 11. 最終的な色差 ΔE00

補正済みの明度差・彩度差・色相差を組み合わせて最終色差を求めます。

```
ΔE00 = sqrt(
  (ΔL / (k_L * S_L))^2
  + (ΔC' / (k_C * S_C))^2
  + (ΔH' / (k_H * S_H))^2
  + R_T * (ΔC' / (k_C * S_C)) * (ΔH' / (k_H * S_H))
)
```

この式が `ciede2000()` で返される色差値です。値が小さいほど色の差が少なく、しきい値以下の色が検索結果として表示されます。
